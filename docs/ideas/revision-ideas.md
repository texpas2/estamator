# Идеи для Revision (накопитель)

Здесь просто складываются идеи по estimator (Estibill) в том виде, как они были озвучены.
Ничего не расписывается. Позже из этого списка будет сформировано задание «Revision».

---

## 2026-09-06

### 1. Регистрация: вид работ → стандартные списки → уровень цен → набор работ

- Во время регистрации спрашиваем у человека, чем он занимается (вид работы).
- Даём ему пройти по стандартным спискам для его вида работ.
- После регистрационных шагов программа определяет уровень цен и сразу набор работ.
- Этот набор работ автоматически формируется и сразу интегрируется в программу
  (не нужно заполнять вручную).

### 2. Локальный веб-сайт из данных компании

- У пользователя уже есть данные по его компании (из регистрации).
- На их основе автоматически формируем ему локальный веб-сайт.
- Фотографии и остальное наполнение сайта берутся из VoiceMate.

### 3. Фото с объекта → работы для сайта

- В estimator даём возможность фотографировать на объекте (на посту).
- Эти фотографии потом становятся у него «работами» (портфолио) для сайта.
- Это нужно доработать в estimator.
